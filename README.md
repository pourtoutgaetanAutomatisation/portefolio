## Mise en ligne avec GitHub Pages
1. Créer un compte sur github.com.
2. Créer un nouveau dépôt public, par exemple `portfolio`.
3. Envoyer tout le contenu de ce dossier dans le dépôt.
4. Ouvrir Settings > Pages.
5. Sous Build and deployment, choisir `Deploy from a branch`.
6. Sélectionner la branche `main` et le dossier `/ (root)`.
7. Enregistrer.
8. GitHub donnera une adresse du type `https://votre-pseudo.github.io/portfolio/`.
